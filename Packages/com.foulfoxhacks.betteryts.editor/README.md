# BetterYTS Editor Tools

**Tools > FoulFoxHacks > BetterYTS** opens a window with three tabs:

| Tab | What it does |
|---|---|
| In-world search | Checks the server, builds a complete search panel (UI, URL pool, video target, event wiring) in one click, and repairs a selected panel (link a player, re-bake the pool). |
| VRChat links | Builds `/search?q=…` links with options (nth result, max length, sort, Shorts, live) for buttons, signs or playlists. |
| ProTV playlists | Turns a YouTube search or playlist into a ProTV playlist: copy a Remote URL link, or save a `.playlist` file into `Assets/BetterYTS/Playlists`. |

There's also **Tools > FoulFoxHacks > Create BetterYTS Search Panel** for a one-click setup.
